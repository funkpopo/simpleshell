# SimpleShell Competitive Analysis & Prioritized Improvement Roadmap (2025–2026)

> **Scope**: Read-only codebase + competitive evaluation comparing **SimpleShell** (`master` after Goals 1–4: commits `3ad1513`, `5d1084f`, `8cb346d`, `8e8e12e`) against 2025–2026 open-source SSH/terminal clients (**WindTerm 2.6/2.7**, **Tabby**, **Electerm**, **XPipe**, **WezTerm**, **Warp**, **Ghostty**).
>
> **Goal 6 Execution Rule**: Every **P0** and **P1** `- [ ]` item below is verified against current `master`, does not duplicate Goals 1–4, and is scoped for complete implementation + automated testing inside this codebase. Large multi-week/hardware/protocol epics are intentionally placed in **P2 / P3**.

## 1. Verified SimpleShell Baseline (Zero False Gaps)

Inspection of `src/`, `native-services/`, `benchmarks/`, `installer/`, `README_zh.md`, and `todo.md` confirms SimpleShell already ships a strong foundation:

- **Packaging, Benchmarking & Performance (Goals 1–3 on `master`)**:
  - **Goal 1 (`3ad1513`)**: Single-step Windows Inno Setup installer generation via `npm run make` (`forge.config.js`, `scripts/makers/maker-inno-setup.js`, `installer/simpleshell.iss`).
  - **Goal 2 (`5d1084f`)**: Development-only `benchmarks/` suite across startup/bundle, terminal pipeline, WebTerminal 50k/500k renderer, and SFTP/UI.
  - **Goal 3 (`8cb346d`)**: Optimized Rust `sftp` / `term-pipe`, main cold-require startup, IPC validation, 500k scrollback search, and virtualized/non-virtualized connection lists while preserving full 50k default / 500k max scrollback (`docs/perf/benchmark-optimization.md`).
- **Global Settings Exposure (Goal 4 `8e8e12e` on `master`)**:
  - Centralized schema/defaults in `src/shared/settings/uiSettingsDefaults.js`, `src/main/settings/configSchemas.js`, `src/main/settings/runtimeSettingsSync.js`, and 7 tabs in `Settings.jsx` (including the new `ConnectionSftpSettings.jsx` tab).
  - Exposed & runtime-wired controls for SSH keepalives/timeouts, reconnect policy, network latency probe interval, SFTP concurrency/retries/idle timeout, File Manager defaults (`defaultSortMode`, `showHiddenFiles`, watch interval, cache TTL, max preview size), storage cache/snapshot quotas, terminal appearance/interaction (`terminalCursorStyle`, `terminalCursorBlink`, `terminalLetterSpacing`, `terminalFontWeightBold`, `terminalCopyOnSelect`, `terminalRightClickSelectsWord`, `terminalMiddleClickPaste`, `terminalMacOptionIsMeta`), command history/suggestion bounds, `defaultLocalShell`, `zmodem.saveDirectory`, updates/notifications/Resource Monitor/recent connections/external editor, `editorFont`, log rotation (`maxFiles`, `compressOldLogs`, `cleanupIntervalDays`), decoupled `webglEnabled`, `cacheEnabled`, and `terminalPerfMonitor` (while removing dead `imageSupported` and `prefetchEnabled` stubs).
- **Transport & Core (`native-services/` + `src/main/connection/`)**:
  - Rust `simpleshell-core` multiplexing SSH, Telnet, Serial, Mosh, and Local PTY/ConPTY + WSL auto-detection.
  - Interactive SSH authentication + SHA-256 host-key prompt (`SSHAuthDialog.jsx`, `sshAuthenticationService.js`), adaptive reconnect recovery (`useReconnect.js`), Local/Remote/Dynamic SOCKS5 port forwarding (`PortForwardingDialog.jsx`), ZMODEM (`rz/sz`).
- **SFTP & Remote Editing (`src/renderer/features/file-manager/`)**:
  - Chunked directory listing, resume manifest (`>=128 MiB`), SHA-256/MD5 integrity verification, directory watch, OSC 7 / OSC 1337 / prompt-regex terminal CWD auto-follow (`useFollowTerminalDirectory.js`), CodeMirror 6 editor with local snapshots & diff, external editor auto-sync, PDF/Media preview, Chmod octal editor.
- **Terminal & AI (`src/renderer/features/terminal/`, `src/renderer/features/ai/`)**:
  - `xterm.js` + WebGL renderer, Rust output syntax highlighting (`highlight-configs.js`), `Ctrl+click` HTTP(S)/IPv4 links (`terminalLinkProvider.js`), incremental/regex/whole-word search (`TerminalSearchAddon.js`), drag-to-split up to 4 panes (`PaneGrid.jsx`, `useSessionDragDrop.js`), Sync Input Groups `G1..G10` (`useTerminalInputSync.js`), command history autocomplete (`CommandSuggestion.jsx`), Resource Monitor, IP Geolocation + World Map, AI Assistant with `<cmd risk="...">` execution & custom regex risk rules, `.ssx` encrypted config export/import + WebDAV auto-sync, OpenSSH `~/.ssh/config` import (currently skips `ProxyJump`/`ProxyCommand`), Master Password.

## 4. Prioritized Improvement Roadmap

### P0 — Critical UI/UX, Functional & Ergonomic Gaps (Goal 6 Mandatory: 4 Items)

- [ ] **`P0-1` [Usability / UI/UX] Global Command Palette (`Ctrl+Shift+P` & Header Trigger)**
  - **Problem Statement in SimpleShell**: Global shortcuts are limited to `Alt+F1` / `Ctrl+Shift+W` (`src/renderer/app/components/SidebarWorkspace.jsx`), `CmdOrCtrl+,` / `CmdOrCtrl+Q` (`src/main/bootstrap/systemMenu.js`), and basic search/copy/paste/clear (`src/renderer/features/terminal/runtime/terminalShortcuts.js`). Users lack a unified keyboard launcher to switch open tabs/panes, connect to saved hosts, launch Quick Connect, open local shells, toggle sidebar tools, invoke shortcut commands, or run tab/theme actions.
  - **Competitor Reference**: Ghostty (`Cmd/Ctrl+Shift+P`), WezTerm (`Ctrl+Shift+P`), Tabby Command Palette, WindTerm Command Palette, Warp (`Cmd/Ctrl+P`).
  - **Concrete Design**:
    1. Pure command registry + fuzzy ranker (`src/renderer/app/lib/commandPalette.js`) aggregating: open tabs & split panes (focus), saved connections (group path + tags), inline Quick-Connect parse (`user@host[:port]` / `ssh://`), local shells, all 9 sidebar panels, shortcut commands, and app/terminal actions (split right/down, duplicate tab, export scrollback, toggle broadcast bar, dark mode, terminal color preset, settings).
    2. Accessible MUI `Dialog` (`src/renderer/app/components/CommandPaletteDialog.jsx`) using strict MUI v9 `slotProps` (`muiV9Props.test.js`), keyboard `ArrowUp`/`ArrowDown`/`Enter`/`Esc`, category chips, and shortcut hints.
    3. Trigger via `Ctrl+Shift+P` (intercepted cleanly before xterm emits control bytes to PTY, while explicitly preserving `Ctrl+K` for bash/zsh `kill-line` when terminal is focused!) plus a compact Command Palette trigger button in `AppShell.jsx` header.
  - **Exact Target Files / Modules**: `src/renderer/app/lib/commandPalette.js` (new), `src/renderer/app/components/CommandPaletteDialog.jsx` (new), `src/renderer/app/AppShell.jsx`, `src/renderer/app/components/SidebarWorkspace.jsx`, `src/renderer/features/terminal/runtime/terminalShortcuts.js`, `src/shared/locales/zh-CN.json`, `src/shared/locales/en-US.json`, `tests/unit/commandPalette.test.js`.
  - **Objective Acceptance Criteria**:
    - Unit tests cover fuzzy ranking, empty-query MRU prioritization, category filtering, and inline `user@host[:port]` detection.
    - Pressing `Ctrl+Shift+P` opens the palette from WelcomePage or active xterm terminal without leaking control bytes to PTY; `Ctrl+K` continues to reach active shells; `Esc` returns focus cleanly to the active terminal.
    - `npm run check` (`eslint .`, `tsc -p tsconfig.preload.json`, `vitest run` incl. `muiV9Props.test.js` & `i18n.test.js`) passes.

- [ ] **`P0-2` [Functionality / Usability] Keyboard-First Tab, Split-Pane & Terminal Ergonomics + Tab/Pane Context Actions**
  - **Problem Statement in SimpleShell**: (1) As explicitly documented in `SidebarWorkspace.jsx`, splits can **only** be created by dragging a tab onto another tab (`useSessionDragDrop.js`)—there is no keyboard shortcut or context menu to split a pane. (2) `terminalShortcuts.js` lacks `Ctrl+Shift+C`/`Ctrl+Shift+V` standard terminal copy/paste, `Ctrl+=`/`Ctrl+-`/`Ctrl+0` font zoom, `Ctrl+Tab`/`Ctrl+Shift+Tab`, `Ctrl+1..9`, `Ctrl+Shift+T` reopen closed tab, and `Alt+Arrow` pane focus cycling. (3) `SessionContextMenu.jsx` lacks **Duplicate Tab**, **Rename Tab**, **Close Other Tabs**, **Close Tabs to Right**, and **Reopen Closed Tab**. (4) `WebTerminalContextMenu.jsx` lacks split actions and **Select All**, and `SidebarRail.jsx` tooltips omit keyboard shortcuts.
  - **Competitor Reference**: WindTerm (H/V split keys, `Alt+Arrows`, Duplicate Tab), WezTerm (mux splits/focus), Ghostty (keyboard splits & zoom), Tabby (`Ctrl+Tab`, `Ctrl+1..9`, `Ctrl+Shift+C/V`, Duplicate Tab).
  - **Concrete Design**:
    1. Extend `src/renderer/features/terminal/model/paneLayout.js`, `src/renderer/app/state/appReducer.js`, and `src/renderer/app/hooks/useSessionTabs.js` with: `splitPane(tabId, paneId, direction, mode)` (duplicate current connection or new local shell, respecting existing 4-pane cap), geometric `focusAdjacentPane(tabId, direction)`, `duplicateTab(tabId)`, `renameTab(tabId, customTitle)`, `closeOtherTabs(tabId)`, `closeTabsToRight(tabId)`, and capped `closedTabsStack` + `reopenLastClosedTab()`.
    2. Register shortcuts in `terminalShortcuts.js` & `SidebarWorkspace.jsx`: `Ctrl+Shift+C` (copy when selection non-empty, keeping `Ctrl+;`), `Ctrl+Shift+V` (paste, keeping `Ctrl+'`), `Ctrl+=`/`Ctrl+-`/`Ctrl+0` (zoom font size cleanly), `Ctrl+Tab`/`Ctrl+Shift+Tab` & `Ctrl+1..9` (tab switch), `Ctrl+Shift+T` (reopen closed tab), `Ctrl+Shift+E`/`Ctrl+Shift+H` (split right / split down), and `Alt+ArrowLeft/Right/Up/Down` (switch pane focus).
    3. Add new actions + shortcut hints to `SessionContextMenu.jsx`, `WebTerminalContextMenu.jsx`, and `SidebarRail.jsx` tooltips.
  - **Exact Target Files / Modules**: `src/renderer/features/terminal/model/paneLayout.js`, `src/renderer/app/state/appReducer.js`, `src/renderer/app/hooks/useSessionTabs.js`, `src/renderer/app/hooks/useSessionDragDrop.js`, `src/renderer/app/components/SessionContextMenu.jsx`, `src/renderer/features/terminal/components/WebTerminalContextMenu.jsx`, `src/renderer/app/components/SidebarWorkspace.jsx`, `src/renderer/app/components/SidebarRail.jsx`, `src/renderer/features/terminal/runtime/terminalShortcuts.js`, `src/renderer/features/terminal/WebTerminal.jsx`, `src/shared/locales/zh-CN.json`, `src/shared/locales/en-US.json`, `tests/unit/paneLayout.test.js`, `tests/unit/appReducer.test.js`, `tests/unit/terminalShortcuts.test.js`.
  - **Objective Acceptance Criteria**:
    - Unit tests verify H/V keyboard split (capped at 4 panes), geometric `focusAdjacentPane`, `duplicateTab`, `renameTab`, `closeOtherTabs`, `closeTabsToRight`, and `reopenLastClosedTab`.
    - Shortcut tests verify `Ctrl+Shift+C`/`V`, zoom keys, tab switching, split keys, and `Alt+Arrow` interception without sending stray escape sequences to PTY.
    - Context menus render accurate disabled states (e.g., Split disabled at 4 panes, Close Others disabled on 1 tab).

- [ ] **`P0-3` [Functionality / Usability] Quick Connect Bar (`user@host[:port]`), Favorites/Pinned Hosts, Tags & Duplicate Connection**
  - **Problem Statement in SimpleShell**: Opening any ad-hoc SSH/Telnet host requires creating a saved record through the multi-tab `ConnectionEditorDialog.jsx`. Meanwhile `ConnectionManager.jsx`, `ConnectionListItems.jsx`, `VirtualizedConnectionList.jsx`, and `WelcomePage.jsx` have no Quick Connect bar, no Pin/Favorite toggle or filter, no Tags search/chips, and no right-click Duplicate Connection option.
  - **Competitor Reference**: Electerm (Quick Connect bar), Tabby (Quick Connect bar), XPipe (Quick Connect + tag/category curation), WindTerm (session cloning).
  - **Concrete Design**:
    1. Pure target parser (`src/renderer/features/connections/lib/quickConnect.js`) supporting `user@host`, `user@host:2222`, `ssh://user@host:port`, `telnet://host:port`, IPv4/hostname, and `[IPv6]:port` -> generates transient session config (`isTransient: true`) compatible with existing `SSHAuthDialog` interactive credential prompts and optional "Save as Connection" action on transient tabs.
    2. Add compact Quick Connect bar to `ConnectionManager.jsx` and quick-connect + "Local Terminal" CTA on `WelcomePage.jsx` (plus `P0-1` Command Palette fallback).
    3. Add optional `pinned` (`boolean`), `tags` (`string[]`), and `colorTag` (`string`) fields across `connectionForm.js`, `ConnectionEditorDialog.jsx`, `useConnectionEditor.js`, `connectionTree.js` (`getConnectionVersion`), `connectionSettings.js`, and `configSchemas.js`; add Star/Pin toggle button + Favorites/Tag filter chips to `ConnectionManager.jsx`, `ConnectionListItems.jsx`, `VirtualizedConnectionList.jsx`, and `ConnectionList.jsx`, plus "Duplicate Connection" in the connection context menu.
  - **Exact Target Files / Modules**: `src/renderer/features/connections/lib/quickConnect.js` (new), `src/renderer/features/connections/ConnectionManager.jsx`, `src/renderer/features/connections/components/ConnectionListItems.jsx`, `src/renderer/features/connections/VirtualizedConnectionList.jsx`, `src/renderer/features/connections/components/ConnectionList.jsx`, `src/renderer/features/connections/components/ConnectionEditorDialog.jsx`, `src/renderer/features/connections/hooks/useConnectionEditor.js`, `src/renderer/features/connections/lib/connectionForm.js`, `src/renderer/features/connections/lib/connectionTree.js`, `src/renderer/features/welcome/WelcomePage.jsx`, `src/main/settings/domains/connectionSettings.js`, `src/main/settings/configSchemas.js`, `src/shared/locales/zh-CN.json`, `src/shared/locales/en-US.json`, `tests/unit/quickConnect.test.js`, `tests/unit/connectionTreeStabilizer.test.js`.
  - **Objective Acceptance Criteria**:
    - Parser tests verify IPv4, `[IPv6]:port`, `ssh://`/`telnet://`, bare host defaults, and validation errors for malformed ports/schemes.
    - Quick Connect launches a live transient session without mutating saved `connections` unless explicitly saved; interactive `SSHAuthDialog` triggers cleanly on missing credentials.
    - `pinned`, `tags`, and `colorTag` persist across restarts, Favorites/tag filters update both standard & virtualized lists (`getConnectionVersion`), and Duplicate generates a fresh editable copy with a unique ID.

- [ ] **`P0-4` [Functionality / UI/UX] Context-Aware AI Assistant (Active CWD, Recent Command & Redacted Terminal Output + Quick Actions)**
  - **Problem Statement in SimpleShell**: In `src/renderer/features/ai/lib/aiSystemPrompt.js` (`buildConnectionContext`), the AI prompt injects **only** `{ host, type }`. Unless the user highlights output and clicks "Send to AI Assistant" (`WebTerminalContextMenu.jsx`, disabled when `!selectedText`), the AI cannot see active CWD (`workingDirectoryStore`), recent executed command (`usePromptTracking`), or visible error output.
  - **Competitor Reference**: Warp AI (block output + CWD context + error explanation), Electerm AI (explain output + script generation), XPipe MCP context.
  - **Concrete Design**:
    1. Read-only `terminalContextCollector.js` (`src/renderer/features/terminal/lib/terminalContextCollector.js`): captures active CWD (`src/renderer/shared/state/workingDirectoryStore.js`), non-secret session metadata (`host`, `username`, `protocol`, `lastCommand`), and bounded trailing scrollback lines (e.g., max 40 lines / 4,000 chars) from xterm `buffer.active`, stripping ANSI escape sequences and redacting sensitive tokens (`Bearer ...`, `Authorization:`, URL credentials, `password=`, PEM private key blocks) before passing into AI state.
    2. Update `aiSystemPrompt.js` (`buildConnectionContext`), `useChatRequest.js`, `AIChatWindow.jsx`, `ChatComposer.jsx`, and `ChatHeader.jsx` with a transparent, toggleable **"Attach Terminal Context"** chip (e.g., `cwd: /etc/nginx · 32 lines`) and 1-click quick-action chips ("Explain recent output/error", "Suggest next command for CWD").
    3. Enable **"Explain Recent Output with AI"** in `WebTerminalContextMenu.jsx` even when `selectedText` is empty.
  - **Exact Target Files / Modules**: `src/renderer/features/terminal/lib/terminalContextCollector.js` (new), `src/renderer/features/terminal/WebTerminal.jsx`, `src/renderer/features/terminal/components/WebTerminalContextMenu.jsx`, `src/renderer/features/terminal/hooks/useTerminalContextMenu.js`, `src/renderer/shared/state/workingDirectoryStore.js`, `src/renderer/features/ai/lib/aiSystemPrompt.js`, `src/renderer/features/ai/AIChatWindow.jsx`, `src/renderer/features/ai/components/ChatComposer.jsx`, `src/renderer/features/ai/components/ChatHeader.jsx`, `src/renderer/features/ai/hooks/useChatRequest.js`, `src/shared/locales/zh-CN.json`, `src/shared/locales/en-US.json`, `tests/unit/terminalContextCollector.test.js`, `tests/unit/aiChatRequest.test.js`.
  - **Objective Acceptance Criteria**:
    - Context collector tests verify bounded line/char caps, ANSI stripping, CWD capture, and secret/token redaction.
    - `buildConnectionContext` unit tests verify structured context when attached, zero context leakage when toggled off, and safe fallback on Welcome tab.
    - Clicking "Explain Recent Output with AI" with empty selection opens AI populated with redacted context and streams cleanly.

### P1 — High-Impact UX, Security & Workflow Parity (Goal 6 Mandatory: 7 Items)

- [ ] **`P1-1` [Functionality] Parameterized Shortcut Commands (`{{var}}` & Session Variables) + Insert/Run Mode**
  - **Problem Statement in SimpleShell**: `src/renderer/features/terminal/ShortcutCommands.jsx` initializes `params: [], tags: []`, yet `renderCommandDialog` exposes no UI for variables or tags and executes raw literal strings.
  - **Competitor Reference**: Warp Workflows (`{{param}}`), WindTerm Quick Bar / Sender, Electerm Quick Commands.
  - **Concrete Design**: Add pure `commandTemplates.js` extracting `{{name}}` / `{{name=default}}` tokens and substituting built-in session variables (`{{host}}`, `{{user}}`, `{{port}}`, `{{cwd}}` via `workingDirectoryStore`); expose tag editing & tag filter pills in `ShortcutCommands.jsx`; open a compact `AccessibleDialog` parameter prompt with live resolved command preview and **Run (`Enter`)** vs **Insert to Prompt (no newline)** mode before sending.
  - **Exact Target Files / Modules**: `src/renderer/features/terminal/model/commandTemplates.js` (new), `src/renderer/features/terminal/ShortcutCommands.jsx`, `src/renderer/shared/state/workingDirectoryStore.js`, `src/shared/locales/zh-CN.json`, `src/shared/locales/en-US.json`, `tests/unit/commandTemplates.test.js`.
  - **Objective Acceptance Criteria**: Unit tests cover template parsing, default values, duplicate variable deduping, built-in context substitution, and missing-required checks; static commands still execute in one click; parameterized commands prompt and respect Run vs Insert-only mode.

- [ ] **`P1-2` [UI/UX] Curated Terminal Color Scheme Presets & Per-Connection Color Badges**
  - **Problem Statement in SimpleShell**: `src/renderer/features/terminal/model/terminalTheme.js` hardcodes only two palettes (`light` and `dark`), lacking popular presets (Dracula, Nord, One Dark, Tokyo Night, Catppuccin, Solarized, Gruvbox) and visual environment badges on tabs.
  - **Competitor Reference**: Ghostty built-in themes, Tabby 150+ schemes, WezTerm built-in schemes, Warp theme library.
  - **Concrete Design**: Expand `terminalTheme.js` with 10 curated high-contrast ANSI 16-color presets (`default-auto`, `one-dark`, `dracula`, `nord`, `tokyo-night`, `catppuccin-mocha`, `catppuccin-latte`, `gruvbox-dark`, `solarized-dark`, `solarized-light`) + fallback; persist `uiSettings.terminalTheme` in `src/shared/settings/uiSettingsDefaults.js`, `src/main/settings/domains/applicationSettings.js`, and `src/main/settings/configSchemas.js`; apply live to cached `xterm` instances via `useTerminalSettingsSync.js`; add visual palette picker + swatch preview in `TerminalSettings.jsx` (and Command Palette action); render subtle connection `colorTag` dot in `CustomTab.jsx` / `SessionTab.jsx`.
  - **Exact Target Files / Modules**: `src/renderer/features/terminal/model/terminalTheme.js`, `src/renderer/features/terminal/hooks/useTerminalSettingsSync.js`, `src/renderer/features/terminal/hooks/useTerminalLifecycle.js`, `src/renderer/features/terminal/runtime/terminalBootstrap.js`, `src/renderer/features/settings/sections/TerminalSettings.jsx`, `src/renderer/features/settings/lib/loadSettingsSnapshot.js`, `src/shared/settings/uiSettingsDefaults.js`, `src/main/settings/domains/applicationSettings.js`, `src/main/settings/configSchemas.js`, `src/renderer/app/components/CustomTab.jsx`, `src/renderer/app/SessionTab.jsx`, `src/shared/locales/zh-CN.json`, `src/shared/locales/en-US.json`, `tests/unit/themeTokens.test.js`.
  - **Objective Acceptance Criteria**: `themeTokens.test.js` validates full 16-color + UI tokens across all presets and safe fallback on unknown IDs; switching theme updates open terminals immediately via `settingsChanged` without reconnect and passes `Ajv` validation + `globalSettingsWiring.test.js`.

- [ ] **`P1-3` [Usability / Functionality] Interactive Multi-Session Broadcast Command Bar**
